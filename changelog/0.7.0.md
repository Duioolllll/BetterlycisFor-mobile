## 한국어

- **휴대폰 음악:** 음악 파일을 선택해 재생목록을 만들고 곡 검색·추가·제거, 이름 변경과 전체 반복·한 곡 반복·무작위를 사용할 수 있습니다.
- **M3U/M3U8:** 목록 파일과 음악 폴더를 선택하면 하위 폴더의 곡을 순서대로 찾아옵니다. 찾지 못한 파일과 인터넷 스트림은 건너뛰고 개수를 표시합니다. 같은 이름의 LRC가 있으면 함께 불러옵니다.
- **로컬 재생:** 화면과 미디어 알림에서 재생·일시정지·이전·다음·위치 이동을 사용할 수 있으며 가사와 위젯에도 상태가 반영됩니다.
- **Spotify:** PKCE로 계정을 연결해 플레이리스트와 곡을 조회하고 Spotify에서 엽니다. Spotify 음원은 Spotify 앱에서 재생합니다. Spotify 개발 모드에서는 앱 소유자의 Premium 계정과 등록된 사용자만 사용할 수 있으며, 곡 조회는 소유하거나 공동 작업하는 목록에 제한될 수 있습니다.
- **검증:** JVM 256개와 브라우저 70개 검사 묶음, Android 16 에뮬레이터의 문서 권한·M3U·합성 오디오 재생과 인증 정보 저장·콜백 검사를 수행했습니다. 실제 Spotify 계정 로그인과 실기기는 별도 검증이 필요합니다. Release에 첨부한 보고서에서 게시 실행 결과를 확인할 수 있습니다.

원본 BetterLyrics를 기준으로 모바일 기능을 계속 확장하고 있습니다. 원본의 모든 기능을 1:1로 구현한 상태는 아닙니다. [대응 현황](../docs/PARITY.md)을 참고하세요.

## English

Import phone music and M3U/M3U8 playlists, play local files, search and edit playlists, and use repeat or shuffle. Matching LRC sidecars in the imported folder provide lyrics. Browse a connected Spotify account's playlists and open tracks in Spotify for playback. Spotify developer-mode access requires a Premium app owner and registered users; track listing may be restricted to playlists the user owns or collaborates on.

Validation includes 256 JVM checks, 70 browser check groups, and Android 16 emulator tests using synthetic documents, audio and Spotify credentials. The release workflow additionally gates publication on installation and update tests. Real Spotify login, physical devices and third-party players remain unverified. Feature parity with the original BetterLyrics is still in progress.
