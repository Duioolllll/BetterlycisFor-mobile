## 한국어

- 이전 앨범 프리셋을 꾸민 뒤 재생바의 항상 표시 설정이 남아 숨겨지지 않던 문제를 수정했습니다. 기존 글꼴과 다른 화면 설정은 유지합니다.
- 이전 버전의 항상 표시 설정은 자동 숨김으로 전환됩니다. 계속 표시하려면 화면 꾸미기에서 **재생 컨트롤 → 항상 표시**를 다시 선택할 수 있습니다.
- 화면 애니메이션이 멈추거나 일부 터치 종료 신호가 누락되어도 재생바가 일정 시간 뒤 숨겨지도록 처리했습니다. 곡 위치 조작 중에는 숨기지 않습니다.
- 기존 서명 키를 유지하여 이전 버전에서 업데이트할 수 있습니다.

Android 16 에뮬레이터에서 합성 재생 데이터로 검증합니다. 실제 휴대폰과 Spotify 계정은 별도 확인이 필요합니다. [지원 범위](https://github.com/Duioolllll/BetterlycisFor-mobile/blob/main/docs/PARITY.md).
