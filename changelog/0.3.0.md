# 0.3.0 — Apple Music 공식 화면 기준 UI

[← 전체 변경 기록 / All records](README.md) · [현재 다운로드 / Current download](https://github.com/Duioolllll/BetterlycisFor-mobile/releases/latest)

공식 iPhone 플레이어, Apple Music Sing 가사, 웹 전체 화면 가사 이미지를 확인하고 배치를 조정했습니다. 작은 커버·곡명·가수·더 보기, 큰 가사와 주변 줄 블러, 재생/음량 영역과 하단 버튼으로 구성합니다. 가로 화면은 큰 커버와 플레이어 왼쪽, 가사 오른쪽입니다.

가사/앨범 화면을 전환하고 실제 미디어 음량을 조절할 수 있습니다. 음량 바는 현재 기기 음량과 동기화하고 고정 음량 기기에서는 비활성화합니다. 재생 위치 옆에는 남은 시간을 표시합니다. 제공처·보정·가사 직접 검색·파일 불러오기·플로팅은 더 보기 메뉴로 정리했습니다. 하단 가운데 파형은 사운드 반응 배경 연결, 오른쪽 목록은 재생 앱 선택입니다.

가사 타이밍과 탐색, 중국어 표시 정책 및 원문 선택, 사운드 반응 배경을 유지합니다. 추가 Android 권한은 없습니다. Bootstrap Icons(MIT)와 Android 시스템 글꼴을 사용합니다. Apple의 이미지·폰트·코드는 포함하지 않습니다.

모의 브리지 브라우저 검증: 기존 화면 29개 그룹, 흐름 9개 그룹, 새 플레이어 7개 그룹. 다섯 화면 크기에서 배치·전환·메뉴·음량·재생 명령을 확인했습니다. API 36 APK 빌드 및 v2/v3 서명 검증을 통과했습니다. 실제 Android 기기에서 음량/재생 연동을 검증하지는 않았습니다. versionCode 7, 같은 개발 서명으로 기존 앱 위에 설치할 수 있습니다.
