## 수정 / Fixes

- 캡처 서비스 종료 시 구체적인 실패 이유를 일반 연결 종료 안내로 덮어쓰지 않도록 수정했습니다. 녹음 장치 해제와 읽기 스레드의 경합을 정리했습니다.
- WebView 브리지 오류는 내부 예외 원문 대신 일반 안내를 표시하고 진단은 logcat에 남기도록 수정했습니다.
- 가사 요청 User-Agent의 저장소 주소를 변경된 GitHub 계정명에 맞게 갱신했습니다.
- 오프라인 회귀 검사 기본 묶음을 명시하고 네트워크 검사는 선택 사항으로 분리했습니다. Android SDK가 없으면 즉시 실패하며 워크플로에서 SDK 경로를 명시합니다.

Capture-service teardown preserves specific failure reasons and avoids a recorder-release/read-thread race. Bridge failures show a generic toast with diagnostics in logcat. The lyrics User-Agent points to the renamed repository account. The offline regression runner uses an explicit default set, keeps network checks opt-in and fails fast when the SDK is missing; the workflow supplies the SDK path.
