## 한국어

- 휴대폰 음악이나 M3U를 불러온 뒤 **전체 재생** 또는 원하는 곡을 눌러 재생할 수 있습니다.
- Spotify 목록의 **재생**, 상세 화면의 **전체 재생**, 곡 선택으로 현재 활성 Spotify 기기에 재생을 요청합니다. 선택한 곡부터 해당 플레이리스트 순서가 유지됩니다.
- Spotify의 공식 재생 제어는 사용하는 계정의 **Premium**과 활성 Spotify 앱 또는 Spotify Connect 기기가 필요합니다. 기기가 없다면 Spotify 앱에서 음악을 시작한 뒤 다시 시도하세요.
- 이전에 Spotify를 연결했다면 **Spotify 다시 연결**을 눌러 새 재생 권한에 동의해야 합니다. Developer Dashboard의 Redirect URI `http://127.0.0.1:43123/callback`은 그대로 사용합니다.

Android 자동 검사는 합성 문서와 오디오, 가짜 인증 정보 및 모의 Spotify 응답으로 재생 요청·권한·갱신·기기 오류를 확인합니다. 실제 Spotify 계정, 실제 기기와 Spotify 서비스에서의 재생은 별도 확인이 필요합니다.

## English

Play imported local playlists or individual tracks immediately. Start Spotify playlists or a selected track on the active Spotify client or Connect device, preserving playlist order. Spotify playback control requires the listening account to have Premium and an active device. Existing connections must reconnect and approve the new playback scope. Android automation uses synthetic Spotify responses; real account playback and physical devices remain unverified.
