# 0.2.2 — 진행도에 따라 흐르는 가사

[← 전체 변경 기록 / All records](README.md) · [현재 다운로드 / Current download](https://github.com/Duioolllll/BetterlycisFor-mobile/releases/latest)

줄이 바뀔 때만 한 번 이동하던 화면을 재생 시각에 따라 계속 따라가도록 바꿨습니다. 줄의 실제 시작 시각, 재생 속도, 곡별 가사 보정을 반영하며, 일시정지하면 진행도와 흐름이 멈춥니다.

탐색 막대를 드래그하는 동안 해당 위치의 가사와 단어 강조를 미리 봅니다. 놓을 때만 탐색을 요청하며 취소하면 실제 위치로 복귀합니다. 확정 직후 음악 앱의 이전 위치가 늦게 도착해도 잠깐 되감기지 않도록 처리하고, 요청이 반영되지 않으면 실제 위치로 복귀합니다. 줄 누르기 탐색도 곡별 보정을 반영합니다.

수동 읽기 중에는 자동 흐름을 잠시 멈추고 현재 가사 복귀를 지원합니다. 긴 간주, 여러 줄로 감기는 마지막 가사, 중첩 보컬, 곡 변경, 움직임 줄이기를 처리합니다. 시간 없는 텍스트에는 임의로 타임스탬프를 붙이지 않습니다. 기본 단어 표시 정책과 사운드 반응 배경, 이전 화면 구성은 유지합니다.

기존 브라우저 29개 기능 그룹(5가지 화면 크기)과 새 흐름 검증 9개 시나리오 그룹을 통과했습니다. APK 빌드·v2/v3 서명 검증을 통과했습니다. 실제 Android 기기 연결은 이번 환경에서 검증하지 않았습니다. versionCode 6 / 같은 개발 서명으로 기존 앱 위에 설치할 수 있습니다.
