## 한국어

Spotify 로그인 시 `redirect_uri: Not matching configuration` 오류에 대응해 인증 주소를 고정했습니다. **Spotify Developer Dashboard**에서 Client ID `32571da108f24ff8a022771cfdc65cf8` 앱의 Redirect URI에 다음 주소를 정확히 추가하고 저장해 주세요.

```text
http://127.0.0.1:43123/callback
```

기존 URI는 유지해도 됩니다. 앱에서 연결을 취소했다가 다시 시도할 수 있습니다. 다른 앱이 해당 포트를 사용 중이면 연결을 다시 시도해 주세요. 고정 주소는 등록값 불일치의 가능성을 줄이지만, 실제 Spotify 계정으로 로그인해 확인해야 합니다.

Android 자동 검사는 실제 앱이 만드는 인증 주소, 임의 state 거부, 정상 state 응답, 포트 재사용 및 충돌 처리를 합성 인증 정보로 확인합니다. 실계정과 실제 휴대폰 동작은 미검증입니다. 이 버전은 0.7.0의 로컬 음악·M3U와 Spotify 플레이리스트 기능을 포함합니다.

## English

Uses a fixed Spotify PKCE loopback redirect to address `redirect_uri: Not matching configuration`. Register `http://127.0.0.1:43123/callback` in the developer app with Client ID `32571da108f24ff8a022771cfdc65cf8`. Existing URIs can remain. Android automation checks the actual generated authorization URL, state validation and callback-port handling using synthetic credentials; real Spotify login and physical devices remain unverified.
