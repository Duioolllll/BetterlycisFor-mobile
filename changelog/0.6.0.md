## 한국어

- **홈 화면 가사 위젯:** 현재 곡과 가사를 표시하고, 지원되는 음악 앱은 재생·일시정지·이전·다음 곡을 제어할 수 있습니다. 위젯을 누르면 앱이 열립니다.
- **위젯 설정:** 어둡게·밝게·반투명 배경, 세 단계 글자 크기, 앨범 커버 표시를 선택할 수 있습니다. 여러 위젯에 같은 설정이 적용되며, 각 위젯의 크기는 홈 화면에서 조절합니다.
- **글꼴:** 나눔고딕·나눔명조·주아·나눔손글씨를 앱에 포함했습니다. 글꼴 이름에서 모양을 미리 보고 선택할 수 있으며, 화면 프리셋을 바꿔도 선택한 글꼴이 유지됩니다. 시스템 글꼴도 선택할 수 있습니다.
- **간결한 설정:** 반복 설명과 장식 문구를 걷어내고 기능 이름과 필요한 상태를 중심으로 정리했습니다.
- **검증:** JVM 233개 검사, 브라우저 61개 검사 묶음과 APK 패키징 검사를 수행했습니다. Android 16에서는 실제 위젯 호스트와 합성 음악 세션으로 권한·가사 전환·재생 제어·크기 조절을 확인합니다.

위젯 갱신은 음악 감지 서비스와 음악 앱의 재생 위치에 의존합니다. 음악 앱이 재생 제어 또는 위치를 제공하지 않거나 기기가 서비스를 중지하면 동작이 제한될 수 있습니다. 실제 휴대폰, 제조사별 홈 화면과 음악 앱, 배터리 사용량은 별도 검증이 필요합니다.

## English

Adds a resizable home-screen lyric widget with current track, timed lyrics, album art and available transport controls. Choose a dark, light or translucent widget background, text size and cover visibility in settings. Widgets share those preferences but can be resized independently.

Adds four offline Korean fonts with live preview: Nanum Gothic, Nanum Myeongjo, Jua and Nanum Pen Script. Font selection survives appearance-preset changes; the reset action restores defaults. Redundant explanatory copy was removed from settings.

Validation includes 233 JVM checks, 61 browser check groups and APK packaging checks. The Android 16 release gate exercises an actual widget host and synthetic media session, alongside clean-install and prior-version update tests. Check the attached validation reports for the published run. Physical devices, third-party launchers/music apps and battery behavior remain unverified.
