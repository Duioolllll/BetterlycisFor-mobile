# BetterLyrics Mobile

BetterLyrics Mobile is an unofficial Android app that displays lyrics alongside music playback. It is an Android implementation inspired by the original BetterLyrics project.

The app can import and play music folders and M3U playlists, browse artists and albums, and edit or export playlists. It can also browse a Spotify account's playlists and control playback on an active Spotify device. Spotify playback control requires a Premium account.

Lyrics can be searched through LRCLIB, NetEase and Kugou or imported from a file. The translucent playback controls hide when idle and reappear when the screen is touched. The app also offers lyric cards, timing adjustments, floating lyrics and a home-screen widget. Listening history is stored on the device.

Android 8.0 or later is required. Download the installer from [GitHub Releases](https://github.com/Duioolllll/BetterlycisFor-mobile/releases/latest). See the [installation guide](docs/INSTALL_EN.md) and [playlist guide](docs/PLAYLISTS.md) for more information. The app interface is currently in Korean.

Not all original features are implemented. The [feature parity document](docs/PARITY.md) describes what is supported and what remains. The project is distributed under [GPL-3.0](LICENSE).
