# BetterLyrics Mobile 설치 안내 — 한국어

[한국어](INSTALL_KO.md) · [English](INSTALL_EN.md) · [简体中文](INSTALL_ZH.md) · [홈](../README.md)

**0.5.0 · Android 8.0 이상(API26+) · 패키지 `io.betterlyrics.mobile` · versionCode 13**
앱 화면은 한국어다. 이 문서는 설치 안내 번역이며 영어/중국어 UI를 제공한다는 뜻은 아니다. 독립적인 비공식 프로젝트다. Android 16을 대상으로 빌드했지만 0.5.0 게시 전 Android16 AVD 설치·시작·업데이트를 검사한다. 실제 휴대폰·음악 재생 검증은 별도다. [검증 범위](VALIDATION.md).

## A. 다운로드와 확인

1. [GitHub 저장소](https://github.com/Duioolllll/BetterlycisFor-mobile)에 접속한다.
2. **Releases** 메뉴를 선택한다.
3. **Latest Release**를 연다. [최신 릴리스 바로가기](https://github.com/Duioolllll/BetterlycisFor-mobile/releases/latest).
4. 아래 **Assets**를 펼쳐 APK를 다운로드한다. `Source code.zip/tar.gz`는 설치 파일이 아니다.
5. 이번 버전 파일명은 `BetterLyrics-Mobile-0.5.0.apk`다. 이후 버전은 해당 Release의 버전·파일명을 따른다.
6. 가능하면 함께 제공하는 `SHA256SUMS`의 SHA-256과 실제 파일을 비교한다. 일치하지 않으면 설치하지 말고 다시 다운로드한다.

[0.5.0 APK](https://github.com/Duioolllll/BetterlycisFor-mobile/releases/download/v0.5.0/BetterLyrics-Mobile-0.5.0.apk) · [체크섬](../downloads/SHA256SUMS). Release가 일시적으로 열리지 않으면 [저장소 APK](https://github.com/Duioolllll/BetterlycisFor-mobile/raw/refs/heads/main/downloads/BetterLyrics-Mobile-0.5.0.apk)를 사용한다. HTML 페이지나 ZIP의 확장자를 APK로 바꾸지 않는다.

컴퓨터에서 확인하는 방법:

```powershell
Get-FileHash .\BetterLyrics-Mobile-0.5.0.apk -Algorithm SHA256
```

Linux는 `sha256sum BetterLyrics-Mobile-0.5.0.apk`, macOS는 `shasum -a 256 BetterLyrics-Mobile-0.5.0.apk`를 쓴다. 체크섬과 서명 일치는 파일 식별이며 Google 보안 승인을 의미하지 않는다.

## B. Android 설치

1. 내려받은 APK를 연다.
2. 시스템이 요구할 때만 APK를 여는 브라우저/파일 앱에 한해 **이 출처의 앱 설치 허용**을 설정하고 돌아온다.
3. 설치 화면에서 **BetterLyrics Mobile** 이름과 표시되는 권한을 확인한다.
4. 설치를 완료한다. 알림 접근과 오디오 등 특수 권한은 최초 사용 시 별도로 요청될 수 있다.
5. 설치가 끝나면 불필요한 출처별 설치 권한을 다시 해제할 수 있다.

Google Play Protect가 경고하면 문구와 원인을 확인한다. 악성 앱 판정 또는 “기기 보호를 위해 앱 차단됨”이 나오면 설치를 중단하고 저장소에 정확한 경고·버전을 알린다. 이 앱은 Google의 검토 통과를 주장하지 않는다. 보안 기능을 끄거나 경고를 무조건 무시하지 않는다.

## C. 최초 실행과 사용

1. 앱을 열고 오른쪽 위 **··· → 음악 감지**에서 Android 알림 접근 안내를 읽고 허용한다. 다른 음악 앱의 미디어 세션·곡 정보를 받기 위해 필요하다.
2. Spotify, YouTube Music, Apple Music, 삼성 뮤직 등 음악 앱에서 노래를 먼저 재생한다. BetterLyrics는 음악 재생 서비스가 아니며 음악 계정 로그인도 받지 않는다.
3. 돌아오면 가사를 자동 검색한다. 여러 세션이 있으면 아래 목록 버튼의 **재생 앱 선택**에서 고른다. 해당 앱이 표준 Android MediaSession을 공개해야 한다. 이름을 열거한 앱 모두가 실기기에서 검증됐다는 뜻은 아니다.
4. 실제 노래와 현재 강조 줄을 비교한다. 다른 버전의 가사면 **··· → 가사 직접 찾기**, **다시 검색**, 또는 **가사 파일 불러오기**를 사용한다. 시간 없는 일반 텍스트는 정확하게 자동 동기화되지 않는다.
5. 일정하게 어긋나면 **이 곡의 가사 시간 보정**을 조절한다. `+`는 가사를 더 일찍, `−`는 더 늦게 표시한다. 탐색/일시정지 후도 확인한다.
6. **··· → 화면 꾸미기**에서 원본 스타일/가사 집중/앨범 중심, 배치·정렬·글자 크기/굵기·여백·흐림·밝기·커버·색상·컨트롤을 바꾼다. 즉시 적용되어 저장된다. 프리셋 초기화는 곡별 시간 보정을 지우지 않는다. 플로팅 가사는 별도 모양이다.
7. **사운드와 배경**에서 소리 반응/유체/정적 배경과 강도를 고른다. 소리 반응에는 **재생 소리에 연결**을 누르고 오디오 권한을 허용한다. 기본 방식이 안 되면 Android10 이상에서 **다른 방식으로 소리 연결**의 시스템 공유 동의를 사용할 수 있다.

오디오 권한은 재생 소리 분석용이며 이 구현은 마이크 입력을 열지 않는다. 녹음 파일 저장/업로드도 하지 않는다. 음악 앱이 캡처를 제한하면 기본 그라데이션을 사용한다. 소리 연결은 가사 표시의 필수 조건이 아니며 앱 화면을 벗어나면 분석을 중단한다. 플로팅 가사를 사용할 때만 **다른 앱 위에 표시** 권한이 필요하다. 파일 가져오기는 사용자가 선택한 문서만 읽는다.

알림 접근이 “제한된 설정”으로 잠긴 경우 설치 차단과는 다른 문제다. 설치한 앱과 권한을 신뢰하는지 먼저 확인하고 Android 앱 정보에 제공되는 제한된 설정 안내를 따른다. 조직/보호자 정책이 차단한 권한을 우회하지 않는다.

## D. 업데이트

GitHub Releases에서 새 APK를 내려받아 기존 앱 위에 설치한다. **패키지명과 서명이 일치하고 versionCode가 낮지 않아야 한다.** 이번 APK는 기존 배포 서명과 일치하는지 검사했다. 소스를 직접 빌드한 debug/새 키 앱은 공개 APK와 다를 수 있다.

업데이트 실패 시 파일 해시·버전·패키지·서명을 확인한다. 다른 서명은 원래 배포자의 같은 키 APK를 받아야 한다. 삭제 후 설치는 마지막 선택이며 설정·곡별 보정·가져온 가사/캐시가 지워질 수 있다. 앱 자체의 외부 백업/내보내기 기능은 없다. 원본 가사 파일과 필요한 설정을 별도로 보관한다.
