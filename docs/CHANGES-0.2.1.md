# 0.2.1 — 가사 중심 화면

왼쪽 위 BetterLyrics 로고·앱 이름·MOBILE / 01을 제거했습니다. 곡 정보와 작은 커버로 시작하며 오른쪽 더 보기(···)에서 설정을 엽니다.

Apple Music의 가사 화면을 참고하여 큰 글자, 넉넉한 줄 간격, 현재 줄의 밝은 강조와 주변 줄의 부드러운 블러를 적용했습니다. 주변 가사의 글자 크기는 줄이지 않습니다. 수동으로 읽을 때는 블러를 해제합니다. 단어별 하이라이트, 가사 줄 누르기 탐색, 현재 줄 복귀는 유지합니다.

재생 버튼의 흰 원 배경을 제거했습니다. 가로 태블릿에서는 왼쪽에 앨범과 플레이어, 오른쪽에 가사를 배치합니다. 작은 가로 화면에는 작은 커버를 사용합니다. 소리에 반응하는 그라데이션, 가사 검색·불러오기 및 기존 텍스트 정책을 유지합니다. 기존과 같은 개발 서명을 사용합니다.

브라우저 모의 환경: 5가지 화면 크기, 29개 기능 그룹 통과. 큰 한국어 글자 22~46, 탐색, 스크롤, 설정 및 사운드 반응을 확인했습니다. API 36 APK 빌드 및 v2/v3 서명 검증을 통과했습니다. 실제 Android 기기 설치/미디어 세션은 이번 환경에서 확인하지 않았습니다.
