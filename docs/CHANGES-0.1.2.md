# 0.1.2 — 중국어 번역·크레딧 표시와 검열 가사 선택

중국어는 제공처의 번역·음역 필드, TTML 언어 fallback 및 LRC 크레딧에서 표시되었습니다. 원문 모델을 파싱한 뒤 한국어/영어 번역 우선 선택, 중국어 보조 필드 숨김, 크레딧 행 제거를 공통 적용합니다. 전체 화면과 플로팅 화면이 동일하게 정리된 모델을 사용합니다. 삭제한 크레딧 때문에 뒤 가사 타임스탬프를 당기지 않습니다.

앱 코드에는 욕설 필터가 없었습니다. 마스킹은 원본 응답의 일부이므로 별표를 임의의 단어로 바꾸지 않습니다. 원곡의 다른 실제 가사 결과, NetEase의 원문 LRC, LRCLIB의 원문 텍스트가 있으면 그중 마스킹 없는 것을 우선합니다. YRC 단어 시간 대신 LRC 줄 시간을 선택할 수 있고, 원문 텍스트만 있으면 시간 없는 텍스트로 표시합니다. 원곡과 다른 순화판은 자동 선택하지 않습니다. 마스킹이 남은 경우 배지로 알립니다.

온라인 캐시 정책을 3으로 올려 이전 선택을 다시 확인합니다. 마스킹이 남은 자동 캐시를 영구 고정하지 않으며 로컬 가져오기 파일은 유지합니다.

147개 JVM/저장소 회귀 검증, JavaScript 문법 검사, Android 36 빌드·APK 서명 검증을 수행했습니다. 실제 Android 음악 앱과의 재생 검증은 수행하지 않았습니다.
