# 0.5.0 코드 검토와 재검토 — 2026-10-27

검토 범위: 번들 웹 UI, 재생·검색·오디오 상태 연동, 네이티브 설정/버전 표시, APK 빌드·배포 절차. 현재 화면을 먼저 캡처하고 수정 뒤 세로·가로·작은 화면을 다시 확인했다.

| 발견 사항 | 수정과 재검토 |
| --- | --- |
| 오디오 상태 캐시가 `message`, `available`을 제외해 같은 상태의 새 오류 설명·표시를 무시 | 두 값을 캐시 서명에 포함. 상태를 고정한 채 설명·가용성만 바꾸는 회귀 검사 통과 |
| 검색 중 닫고 다시 열면 버튼이 계속 비활성화 | 검색 화면을 열 때 제출 상태 초기화. 응답 없이 닫기·재진입·재제출 검사 통과 |
| 탐색 슬라이더가 보조 기술에 0–1000 값만 제공 | 경과/전체 시간의 `aria-valuetext`와 탐색 미리보기 검사 통과 |
| 웹 설정은 0.4.1, 네이티브 안내는 고정 버전 표시 | 오래된 웹 버전 제거, 네이티브 안내는 실제 설치 패키지 버전 사용 |
| 디자인 적용 후 320px 폭에서 컨트롤 겹침 | 두 줄 배치로 수정. 320–1280px에서 주요 버튼 44px 터치 영역·겹침 없음 확인 |
| 낮은 화면에서 처음 실행 동작이 플레이어에 가림 | 플레이어 공간을 제외한 빈 화면 영역에서 연결/검색 동작에 스크롤로 접근 가능하도록 수정 |
| UI 검사가 `file://`만 사용해 관리형 Chromium에서 실행 불가 | `BETTERLYRICS_PREVIEW_URL`로 동일 자산을 HTTP로 검사. 기존 assertion을 유지하고 게시 전 UI 게이트 추가 |

## 실행 결과

- JVM 214개, 오디오 기준 출력 2,073프레임, APK 패키징 5개 통과.
- UI 29 + 흐름 9 + 플레이어 7 + 꾸미기 5 + 이번 회귀 6 = 브라우저 검사 56개 묶음 통과. JavaScript 예외 없음.
- 기존 UI·플레이어: 360×740, 412×915, 812×375, 1280×800, 800×1280. 추가 회귀: 320×640 포함.
- JDK 17 / API 36 / Build Tools 36.0.0으로 Debug와 Release 빌드. 기존 공개 APK의 인증서 일치 확인.

출시 검사는 Release의 `RELEASE_VALIDATION.json`, `UI_VALIDATION.json`, `INSTALL_VALIDATION.json`을 따른다. 물리 기기나 실제 음악 앱의 권한·재생 연동을 검증했다는 뜻은 아니다. 가사 제공처의 이용 조건과 기존 하드웨어 검증 범위는 [VALIDATION.md](VALIDATION.md)를 따른다.
