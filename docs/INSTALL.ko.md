## 1. APK 설치

Android **8.0 이상**이 필요합니다. 음악은 Spotify, YouTube Music, Apple Music, 삼성 뮤직 등 별도 음악 앱에서 재생합니다. 해당 앱이 Android 미디어 세션을 제공해야 감지할 수 있습니다.

1. **[0.3.0 APK 다운로드](https://github.com/sdcom1214/BetterlycisFor-mobile/raw/refs/heads/main/downloads/BetterLyrics-Mobile-0.3.0.apk)**를 누릅니다. GitHub 파일 화면이 열리면 **Download raw file**을 사용합니다. 저장소의 **Code → Download ZIP**은 설치 파일이 아닙니다.
2. 내려받은 `BetterLyrics-Mobile-0.3.0.apk`를 엽니다. 설치 출처 안내가 나오면 해당 브라우저/파일 앱의 **설정 → 이 출처 허용**을 확인한 뒤 설치 화면으로 돌아옵니다. 메뉴 이름은 기기마다 다릅니다.
3. 설치가 끝나면 BetterLyrics Mobile을 엽니다. 필요가 끝난 설치 출처 권한은 다시 끌 수 있습니다.

다운로드 파일 크기는 **103,221바이트**입니다. [SHA-256 체크섬](../downloads/SHA256SUMS)과 [서명 정보](../downloads/README.md)를 제공합니다. 체크섬·서명 일치는 배포 파일의 식별 정보이며 보안 승인을 의미하지 않습니다.

## 2. 음악 감지 연결

1. 앱 오른쪽 위 **··· → 음악 감지**를 누릅니다.
2. Android의 알림 접근 화면에서 BetterLyrics를 선택하고 권한 내용을 확인한 뒤 허용합니다.
3. 음악 앱에서 노래를 재생하고 BetterLyrics로 돌아옵니다. 여러 음악 앱이 보이면 오른쪽 아래 목록 버튼의 **재생 앱 선택**에서 고릅니다.

**설치 후** 알림 접근 설정이 제한된 경우에만, 앱과 권한을 신뢰한다면 Android **설정 → 앱 → BetterLyrics Mobile → 더 보기 → 제한된 설정 허용**이 제공되는지 확인합니다. 이 메뉴는 Android 버전·기기에 따라 다르며 설치 자체를 막는 Play Protect 차단과 별개입니다.

## 3. 선택 기능

| 기능 | 사용 방법 |
| --- | --- |
| 플로팅 가사 | **··· → 플로팅 가사**, 필요할 때 다른 앱 위 표시 권한 허용 |
| 사운드 반응 배경 | 아래 가운데 파형 버튼 또는 **··· → 사운드와 배경 → 재생 소리에 연결** |
| 대체 소리 연결 | 기본 방식이 안 되면 **다른 방식으로 소리 연결**. Android 10 이상에서 시스템 동의 필요 |
| 가사/앨범 전환 | 왼쪽 아래 인용부호 버튼 |
| 곡별 싱크 | **··· → 이 곡의 가사 시간 보정**. `+`는 더 일찍, `−`는 더 늦게 표시 |

사운드 연결에 오디오 권한이 표시되어도 이 구현은 마이크 입력을 열지 않습니다. 음악 앱이 재생 소리 공유를 제한하면 기본 그라데이션으로 동작합니다. 소리 연결은 가사 감지에 필수가 아닙니다.

## 4. 업데이트와 문제 해결

- **업데이트:** 같은 패키지·같은 서명의 APK는 기존 설치본 위에 설치할 수 있습니다. 공개 소스를 처음 빌드하면 별도 키가 생성되어 다운로드 APK와 서명이 다릅니다. 서명이 다른 앱을 설치하려면 기존 앱 삭제가 필요할 수 있으며 설정과 가져온 가사는 삭제됩니다. 현재 버전의 외부 백업 기능은 없습니다.
- **다운로드가 안 됨:** 위 APK 직접 링크를 일반 브라우저에서 열거나 GitHub 파일 화면의 **Download raw file**을 누르세요. HTML 페이지나 소스 ZIP의 확장자를 APK로 바꾸지 마세요.
- **Play Protect가 “기기 보호를 위해 앱 차단됨” 표시:** 차단 문구를 확인하고 설치를 중단하세요. 이 시험판은 Google 보안 검토를 통과했다고 주장하지 않습니다. Play Protect를 끄는 방법은 설치 절차에 포함하지 않습니다. 잘못된 탐지라면 개발자가 Google의 이의 제기 절차를 확인해야 합니다.
- **곡/커버가 안 나옴:** 알림 접근을 확인하고 음악 앱에서 먼저 재생한 뒤 재생 앱을 다시 선택하세요. 해당 앱이 커버나 재생 정보를 제공하지 않으면 표시할 수 없습니다.
- **가사가 다르거나 싱크가 어긋남:** **···**의 직접 검색에서 같은 곡·같은 버전 후보를 선택하거나 로컬 가사를 불러오세요. 일정하게 어긋나면 곡별 보정을 사용합니다. 원본 타임스탬프가 부정확하거나 시간 정보가 없으면 자동 보정으로 해결할 수 없습니다.

실제 Android 기기에서 설치·권한·음악 앱 연동을 실행한 검증은 아직 없습니다. [검증 범위](VALIDATION.md)를 확인하세요.
