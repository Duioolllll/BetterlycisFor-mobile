## Applied layout

The phone lyrics reference uses a small cover and song information at the top, large left-aligned lyrics, a brighter active verse, softened other verses, a scrubber with elapsed/remaining time, filled double-triangle previous/next buttons, a large central transport icon, a volume row and a bottom action row. Relative to 0.2.2, the playback section is taller and starts earlier, while utility metadata and actions have moved to the menu. The wide reference informs the cover/player-left and lyrics-right composition and the larger artwork.

## Platform and capability differences

Android system typefaces are used, so exact glyph shapes differ from Apple's system fonts. Bootstrap Icons v1.13.1 (MIT) supply the selected controls; SF Symbols are not copied. The middle bottom button connects this app's sound-reactive background; it does not claim to be AirPlay. The list button selects a connected music app rather than an Apple library queue. Album view shows the actual static image supplied by Android MediaSession. Favorites, Apple Music Sing vocal removal, Apple subscriptions and Apple catalog integration are not simulated.

The existing timestamp-driven flow remains, including scrub preview and real/estimated word-timing distinction. Static references do not establish exact motion curves, so no frame-for-frame animation claim is made.

Official images were used only for internal inspection and are not distributed. UI screenshots generated by tests use original text and geometric test cover art and are not included as deliverables.
